# Changelog

## 1.0.0
- Первый выпуск: кнопка без дребезга, `pressed()`, `released()`, `clicked()`, `doubleClicked()`, `longPressed()`, `repeat()`, время удержания.
- Не блокирует программу, обновлять вручную не нужно; обработчики по желанию.
- Режимы PULLUP, PULLDOWN, EXTERNAL; предупреждение для пинов ESP32 без подтяжки.
- Понятные подсказки и `diagnose()` на русском, казахском и английском.
